How the PLC uses this board

  1. Set dates on the Calendar tab. Pick the week's type (troop meeting, PLC, hike, campout, service, COH).
  2. Draft each meeting in Meeting Builder. Roll random or pick from the library, then "Save to week" to assign it.
  3. Pick trips from Trips & Trails — favorite the ones you want to revisit, schedule them straight to a week.
  4. Run training using the Gauntlet — scenarios, EDGE tasks, event cards, and challenge questions.
  5. Print the plan from Export for the SM and committee review.
